# 微信首次建号的默认昵称

小程序首次创建统一账号时，默认昵称依次为 wx_10052、wx_10053、wx_10054 等。用户仍可从账号中心修改昵称；再次登录、绑定微信均不覆盖现有昵称。已有账号的昵称保持原值，内部 username、UUID 和微信身份绑定方式不变。

编号保存在 settings 的 wechat-display-name-sequence 中，使用现有 APP_KEY 加密的 JSON 记录下一编号。首次使用自动建立该记录，无需改表；数据库结构与现有在线更新协议保持兼容。编号不从用户数量、昵称、过期票据或 rate_limits 推算，因此清理日志及修改昵称不会导致重置。

分配编号、创建账号、来源记录与绑定身份在同一事务中完成。计数行通过 InnoDB 行锁串行分配；失败事务不会消耗编号。微信建号及扫码消费可针对 MySQL 1213 死锁有限重试整个事务，最多五次，只重试已经回滚的数据库工作；普通异常不重试，其他业务事务默认行为不变。编号状态损坏会拒绝建号，不会静默重置。

验证包括从 10052 开始、连续分配、已有及自定义昵称保留、微信绑定、真实失败回滚、重试边界、六个独立 PHP 进程同时建号、同一身份并发建号及实际扫码/昵称修改 HTTP 流程。

此项包含在 1.0.8 版本中，支持从 1.0.7 在线升级。
