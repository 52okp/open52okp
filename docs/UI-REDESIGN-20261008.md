# 2026-10-08 整体 UI 整改

参考 https://hao.52okp.com/ 的实际最终样式：背景 #f5f6f8、主色 #3478f6、白色卡片、细边框、蓝色选中导航、紧凑侧栏。页面使用本地系统字体与内联 SVG 图标。

## 覆盖范围

- 公共框架：首页、账号中心、管理后台、API 接入文档与隐私页面统一导航和页脚。按用户要求移除所有页面顶部品牌/账号中心及右侧登录区域；已登录账号入口与退出操作迁入导航或认证页页脚。
- 首页：浅蓝横幅、账号服务快捷卡片、登录方式说明与登录流程。
- 登录、注册、找回密码、二次验证、恢复码和退出确认：共用桌面双栏框架，手机端收敛为单栏表单。
- 账号中心：邮箱、微信和二次验证状态概览；资料、安全与密码表单。补充已有二次验证页面的开启入口。
- 后台：用户头像、状态标签、搜索标签、搜索空状态、分页、审计记录，以及应用与服务配置表单。
- API：保留接口说明和示例，统一蓝色主题，代码区保持独立滚动。

所有表单仍使用原有路由、CSRF、票据和字段。动态内容继续经 HTML 转义。登录标签支持方向键、Home/End、选中状态和焦点管理。新增跳到主要内容链接，并完善手机端账号和管理入口的无障碍名称。

## 资源

统一样式位于 public/assets/app.css；文档样式位于 public/assets/api-docs.css。执行 `python tools/fingerprint.py` 会生成三项带内容指纹的资源和 resources/assets.json。API 的既有 JavaScript 资源仍沿用原文件。
